# Exa

Web search, code search and page contents from Exa's search engine.

**Remote server:** `https://mcp.exa.ai/mcp`

## Secrets

Wisp keeps these in the system keychain.

- **API key** (optional) (`x-api-key`) — Optional. Without a key, Exa's free limits apply. [Get one](https://dashboard.exa.ai/api-keys).

## Notes

Exa's hosted server. Works without a key; add one for higher limits.

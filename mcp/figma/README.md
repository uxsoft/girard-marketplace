# Figma

Design context, variables, components and screenshots from Figma files.

**Remote server:** `https://mcp.figma.com/mcp`

## Notes

Wisp signs in with OAuth in your browser after you add it: open **Settings → MCP servers** and click **Sign in**. Wisp keeps the tokens in the system keychain and refreshes them; the agents never see them.

Figma only lets clients it knows register for sign-in, so Wisp registers under the name `Claude Code`.

Upstream: <https://help.figma.com/hc/en-us/articles/32132100833559>

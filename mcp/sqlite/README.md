# SQLite

Query and change a local SQLite database file.

**Runs locally:** `uvx mcp-server-sqlite --db-path {db_path}`

## Settings

- **Database file** — The full path of the .db file. It is created if it doesn't exist.

## Notes

Needs [uv](https://docs.astral.sh/uv/) (`uvx`). This is the reference server from the archived `modelcontextprotocol/servers` collection.

Upstream: <https://github.com/modelcontextprotocol/servers-archived/tree/main/src/sqlite>

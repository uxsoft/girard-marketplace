# Brave Search

Web, news, image and local search with the Brave Search API.

**Runs locally:** `npx -y @brave/brave-search-mcp-server`

## Secrets

Wisp keeps these in the system keychain.

- **API key** (`BRAVE_API_KEY`) — A Brave Search API key. The free plan is enough to start. [Get one](https://api-dashboard.search.brave.com/app/keys).

## Notes

Needs Node.js (`npx`) and a Brave Search API key.

Upstream: <https://github.com/brave/brave-search-mcp-server>
